# Projeto de Cadastro e Alerta de Celulares

Este projeto permite que os usuários cadastrem seus celulares e emitam alertas em caso de perda, extravio ou furto. As forças de segurança podem usar o sistema para verificar e apreender celulares com base nos alertas emitidos.

## Tecnologias Utilizadas

- **Back-end**: Spring Boot
- **Front-end**: React
- **Banco de Dados**: PostgreSQL

## Estrutura do Projeto

- **Backend**: Diretório `src\main\java\com\nst\alertacellgcmr` com todos os arquivos Java para a API Spring Boot.
- **Frontend**: Diretório `...` com todos os arquivos React.
- **Banco de Dados**: Configurações para o PostgreSQL no arquivo `application.properties`.

## Pré-requisitos

- Java 21 (LTS)
- Node.js 22.13.1
- PostgreSQL
